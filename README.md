### Project Overview & Instructions
GlowUp Studio is an interactive, responsive web application offering holistic self-care guidance, skincare rituals, routine planning, and expert consultations.

To run the project locally:
1. Clone or download the repository.
2. Open `index.html` in any modern web browser (Google Chrome, Microsoft Edge, Mozilla Firefox, Safari).

---

### Implemented jQuery Features (Part 1):
- **Task 1 (Selectors & Events):** Personalized welcome greeting with input validation, and dynamic Light/Dark theme toggle using `.toggleClass()`.
- **Task 2 (Animations):** FAQ accordion animated with `.slideToggle()` and queue protection (`.stop()`), plus status alert fade effects (`.fadeIn()`, `.fadeOut()`).
- **Task 3 (Content Filtering):** Real-time ritual search combined with multi-category controls and zero-match fallback feedback.
- **Task 4 (Dynamic Content):** Dynamic daily routine checklist with delegated event handlers (`.on('click', '.btn-remove-item')`) and counter updates.
- **Task 5 (Form Validation):** Comprehensive consultation booking form with email regex validation, inline field-specific errors, and demo feedback.
